# YouTube Clone

A responsive, static recreation of the YouTube browsing interface built with HTML and CSS. The project focuses on practicing page structure, responsive layout, navigation patterns, and visual styling.

## Run locally

Open `index.html` in a browser or serve the repository with any static file server:

```bash
python -m http.server
```

The page uses local assets for icons, thumbnails, and styles, with Google Fonts loaded by the browser.
